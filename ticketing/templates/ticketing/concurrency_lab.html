The Concurrency Mechanism Under Test
When multiple buyers click "Book" in the same millisecond for the last remaining seat, standard ORM queries produce a read-modify-write race condition where both threads see 1 seat remaining and both increment the counter (overselling).

Strata Solution: 
with transaction.atomic():
    # Row-level lock: blocks all concurrent transactions until this commit finishes
    event = Event.objects.select_for_update().get(id=event_id)
    if event.tickets_sold >= event.total_capacity:
        raise ValidationError({"error": "Event is completely sold out."})
    
    attendee, _ = Attendee.objects.get_or_create(email=email, defaults={"name": name})
    ticket = Ticket.objects.create(event=event, attendee=attendee)
    event.tickets_sold += 1
    event.save(update_fields=['tickets_sold'])
